# Complejo

Proyecto Java de construcción de un complejo residencial que modela elementos como edificios, casas, materiales y sistemas de tuberías.

## Descripción

Este proyecto incluye clases para representar:
- `Casa`
- `Edificio`
- `Almacen`
- `Canios`
- `Material`
- `Cemento`
- `Pintura`

También contiene diagramas UML en `src/main/java` para apoyar el diseño del sistema.

## Estructura del proyecto

- `src/main/java`: código fuente principal
- `src/test/java`: pruebas unitarias
- `pom.xml`: configuración de Maven

## Requisitos

- Java JDK 8 o superior
- Maven

## Uso

Para compilar el proyecto:
```bash
mvn clean compile
```

Para ejecutar las pruebas:
```bash
mvn test
```
